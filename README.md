# 安医大课程视频助手

中文 | [English](README.en.md)

适用于安徽医科大学网络教学平台的 Tampermonkey 视频辅助脚本，帮助管理课程视频播放和观看进度检查。

[从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/604904)

## 功能

- 支持课程页面和学校 WebVPN 课程页面。
- 对课程视频静音，提供 1、1.25、1.5、2 倍速选择。
- 辅助后台播放，并在播放状态异常时提示或尝试恢复。
- 在视频结束后刷新页面，检查平台显示的未观看区段；可从未观看区段附近补看到视频结尾。
- 在能确认活动状态时，尝试寻找未完成视频并切换到下一个视频，跳过测试。

平台记录、浏览器后台调度和网络状况可能影响结果；播放结束不代表平台一定记录完整，请以课程平台的实际进度为准。黄色区段的位置是根据页面进度条估算的。浏览器最小化时可能暂停，无法保证后台持续播放。

## 安装

1. 在 Microsoft Edge 或其他兼容浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [Greasy Fork 脚本页面](https://greasyfork.org/zh-CN/scripts/604904)，选择安装。
3. 如果浏览器要求，按照 Tampermonkey 的提示允许用户脚本运行。
4. 打开课程页面，在视频助手中选择倍速并点击“开始”。

具体效果取决于平台页面结构和课程配置；本项目尚未验证所有课程。需要补看时，先停止助手，再点击“补看黄色区段”。

## 隐私与功能范围

脚本不包含答题或收费功能，不提供用户账号或 API 密钥。脚本使用浏览器本地存储保存倍速，以及课程运行状态和刷新核对所需的信息；课程页面和活动编号会用于运行时状态判断。脚本本身未配置向第三方服务发送数据的功能。
